# 속풀이 인형방

> 내 브라우저 안의 비밀 인형방

`속풀이 인형방`은 누구나 주소로 접속할 수 있지만 사용자의 사진, 대상 이름, 인형과 저주 기록을 외부로 전송하거나 공개하지 않는 로컬 우선 스트레스 해소 웹앱입니다. 실제 효력을 주장하지 않는 가상 놀이이며, 사실적인 공포·고어·피·신체 훼손 표현과 소리를 사용하지 않습니다. 만 14세 이상 이용을 권장합니다.

## MVP 개요

- 얼굴 사진과 최대 한글 4글자의 대상 이름으로 헝겊인형을 만듭니다. 자유롭게 글을 쓰는 감정 문구 기능은 포함하지 않습니다.
- 바늘, 흔들기, 부적, 인형 태우기, 주문 외우기, 정화하기의 6개 도구를 제공합니다.
- 오컬트 저주 5개와 장난 저주 5개를 선택할 수 있으며, 부적에는 사용자가 작성한 문구가 아니라 선택한 저주명이 표시됩니다.
- 부적에 연결된 주문을 길게 눌러 시전하며, 별도의 주문 종류를 다시 선택하지 않습니다.
- 인형은 최대 5개까지 현재 부적·바늘·그을림 상태와 함께 브라우저에 저장합니다.
- PC와 모바일 반응형 화면 및 키보드 접근성을 지원합니다.

## 시각 방향

전체 공간은 밝은 크림색 한지 벽과 꿀색 나무 작업대를 사용한 `따뜻한 한지 인형 공방`입니다. 탁한 분홍·연보라·옅은 민트와 노란 부적·붉은 글씨를 포인트로 쓰고, 둥근 달 모양 무드등과 절제된 바느질 소품을 배치합니다. 기본 화면은 밝고 따뜻하게 유지하며, 저주 실행 순간에만 잠시 어두워졌다가 곧바로 원래 공방으로 돌아옵니다.

## 로컬 저장과 사진 정책

- JPG, PNG, WebP 형식과 최대 10MB 원본을 지원합니다. HEIC는 MVP에서 지원하지 않습니다.
- 사진은 브라우저 안에서 1024×1024 WebP로 변환·압축하고 EXIF 위치정보 등 원본 메타데이터를 제거합니다.
- 원본과 변환 이미지, 대상 이름, 인형과 저주 기록은 외부 서버나 외부 분석 서비스로 전송하지 않습니다.
- 인형 데이터와 이미지는 IndexedDB에, 단순 설정값은 localStorage에 저장합니다.
- 브라우저 데이터를 삭제하거나 시크릿 모드·다른 기기·다른 브라우저를 사용하면 저장 내용이 사라질 수 있습니다.

## 확정 기술 스택

- React, TypeScript, Vite
- 별도 UI 프레임워크 없는 CSS
- 얼굴 자르기·합성과 필요한 불꽃·재·입자 효과용 HTML Canvas
- 흔들림과 일반 UI 동작용 CSS 애니메이션
- IndexedDB와 경량 `idb` 라이브러리, 단순 설정용 localStorage
- Vitest, React Testing Library
- 별도 화면 라우터 없이 애플리케이션 상태로 화면을 전환하는 단일 페이지 애플리케이션
- 백엔드, 외부 API, 사용자 분석 도구 없음

## 저장소와 배포 원칙

GitHub 저장소는 비공개로 유지합니다. 구현 완료 후 별도 단계에서 Cloudflare Pages가 비공개 저장소를 연결해 빌드하도록 설정하며, 배포된 웹사이트는 주소로 누구나 접속할 수 있습니다. Cloudflare Web Analytics를 포함한 사용자 분석 기능은 활성화하지 않습니다. 사용자 사진과 로컬 인형 데이터는 정적 배포물이나 Git 저장소에 포함하지 않습니다.
