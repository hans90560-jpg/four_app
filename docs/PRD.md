# 속풀이 인형방 PRD

- 문서 버전: v0.7
- 작성일: 2026-08-24
- 상태: MVP 확정 요구사항 반영본(일부 세부 사항 협의 중)
- 정식 서비스명: `속풀이 인형방`
- 부제: `내 브라우저 안의 비밀 인형방`

## 1. 제품 개요

`속풀이 인형방`은 개인적인 스트레스 해소를 위한 무료 로컬 우선 웹앱이다. 웹사이트 자체는 주소를 통해 누구나 접속할 수 있지만, 사용자의 사진, 대상 이름, 인형과 저주 기록은 외부 서버나 분석 서비스로 전송하거나 다른 사용자에게 공개하지 않는다.

사용자는 스트레스를 주는 대상의 얼굴 사진과 이름으로 귀여운 수제 헝겊 봉제인형을 만들고, 따뜻한 한지 인형 공방 안에서 바늘·흔들기·부적·인형 태우기·주문 외우기·정화하기를 사용할 수 있다. 자유롭게 감정을 적는 감정 문구, 문구 작성, 속마음 종이 기능은 MVP에 포함하지 않으며 향후 확장 후보에도 두지 않는다. 인형 생성 시 사용자가 입력하는 정보는 사진과 대상 이름뿐이고, 부적에는 사용자가 작성한 문구가 아니라 선택한 저주명이 표시된다.

이 서비스는 실제 효력이 있는 저주를 제공하거나 주장하지 않는다. 모든 저주와 상호작용은 화면 안에서만 이루어지는 가상의 스트레스 해소 놀이다. 사실적인 공포·고어·피·상처·신체 훼손 표현은 사용하지 않는다.

## 2. 서비스 원칙과 비목표

### 2.1 서비스 원칙

- 로그인과 회원가입 없이 이용한다.
- 웹사이트는 주소를 통해 누구나 접속할 수 있다.
- 사진, 대상 이름, 인형과 저주 기록은 외부 서버나 외부 분석 서비스로 전송하지 않고 현재 브라우저에만 저장한다.
- 저장한 인형은 같은 기기와 같은 브라우저에서만 다시 불러올 수 있다.
- PC와 모바일 브라우저를 지원하는 반응형 웹으로 제작하고 키보드 접근성을 유지한다.
- 모든 저주·부적·주문은 서비스용 창작 표현이며, 실제 주술의 효능이나 정통성을 주장하거나 의식 수행법을 안내하지 않는다.
- 배경음과 효과음을 포함한 모든 소리 기능은 사용하지 않는다.

### 2.2 비목표

- 회원가입, 로그인, 클라우드 저장, 기기 간 동기화
- 공개 갤러리, 사용자 콘텐츠 검색, SNS 공유, 공개·공유 링크, 댓글, 메시지, 커뮤니티
- 사용자 추적 및 Cloudflare Web Analytics를 포함한 외부 분석 기능
- 실제 상대를 공격·위협하거나 현실의 위해를 유도하는 기능
- 실제 주술의 효능·정통성을 주장하거나 의식 수행법을 안내하는 기능
- 사실적인 공포, 고어, 피, 상처, 신체 훼손 묘사
- 배경음, 효과음 등 모든 소리 기능
- 네이티브 iOS·Android 앱, 결제, 광고, 구독

## 3. 대상 사용자와 핵심 가치

### 3.1 대상 사용자

- 일상적인 인간관계나 업무 스트레스를 가볍고 유머러스하게 풀고 싶은 사용자
- 귀여운 수제 인형과 비고어 창작 저주 연출을 좋아하는 사용자
- 자신의 사진과 인형 기록을 외부에 공개하거나 전송하고 싶지 않은 사용자
- 만 14세 이상 이용을 권장한다.
- 생년월일 입력이나 별도의 연령 확인 절차는 제공하지 않는다.

### 3.2 핵심 가치 제안

“누구에게도 보내지 않고, 내 브라우저 안에서만 조용히 털어내는 귀여운 디지털 저주인형.”

## 4. 인형 디자인

- MVP에서는 승인된 콘셉트를 바탕으로 여성형 인형 1종만 제작한다.
- 남성형 인형은 MVP에서 제외하고 향후 확장 후보로 둔다.
- 무서운 실제 제웅이 아니라 한국적인 제웅의 기본 실루엣을 부드럽고 귀엽게 재해석한 수제 헝겊 봉제인형으로 표현한다.
- 옷은 밝은 흰색 또는 크림색 계열의 원피스로 한다.
- 중앙 얼굴 사진 영역은 업로드한 사진으로 빈틈없이 채운다.
- 대상 이름은 최대 한글 4글자이며 원피스 위에 상단부터 하단까지 큰 붉은 세로 붓글씨로 표시한다.
- 시작 화면과 보관함 빈 상태에는 얼굴 사진이 없는 기본 헝겊인형을 사용한다.
- `assets/concepts/doll-concept-v1.png`는 인형 형태, 원피스, 붉은 세로 붓글씨와 얼굴 부적의 관계를 위한 승인 참고 이미지다. 이미지의 어두운 배경과 연소 표현보다 이 문서의 밝은 공방 및 비고어 연출 원칙을 우선한다.

## 5. 배경과 전체 분위기

- 전체 배경은 `따뜻한 한지 인형 공방`이다.
- 밝은 크림색 한지 벽과 꿀색 계열의 부드러운 나무 작업대를 사용한다.
- 포인트 색상은 탁한 분홍, 연보라, 옅은 민트, 부적의 노랑과 붉은 글씨다.
- 소품은 붉은 실타래, 작은 바느질 상자, 천 조각, 노란 부적 묶음 정도로 절제한다.
- 촛불 대신 둥근 달 모양 무드등을 사용한다.
- 그림자는 연하게 표현하고 무서운 어두운 구석을 만들지 않는다.
- 해골, 검은 촛불, 낡은 제단, 짙은 연기, 공포스러운 마법진은 사용하지 않는다.
- 기본 화면은 밝고 따뜻하게 유지한다.
- 저주가 실행되는 순간에만 배경이 살짝 어두워지고 서비스용 창작 문양이 빛난 뒤 곧바로 원래 공방으로 돌아온다.
- 전체 인상은 `귀여운 인형 수선 공방에 비밀 부적 기능이 숨어 있는 느낌`으로 한다.

## 6. 핵심 화면과 배치

### 6.1 시작 화면

- 중앙에 얼굴 사진이 없는 기본 헝겊인형을 표시한다.
- 서비스명 `속풀이 인형방`과 부제 `내 브라우저 안의 비밀 인형방`을 표시한다.
- `새 인형 만들기`와 `내 인형 보관함` 버튼을 크게 배치한다.
- 하단에 `사진과 인형은 이 브라우저에만 저장됩니다`라는 안내를 표시한다.
- 만 14세 이상 이용을 권장한다는 짧은 안내를 표시한다.
- 실제 효력을 주장하지 않는 가상 놀이와 이용 태도에 관한 다음 성격의 안내를 짧게 표시한다.

  > 실제 효력을 주장하지 않는 가상 스트레스 해소 놀이입니다. 결과를 타인에게 보내거나 위협하는 용도로 사용하지 마세요.

- 오른쪽 위에 설정과 서비스 안내 진입 버튼을 둔다.
- 모바일에서는 두 주요 버튼을 세로로 배치한다.

### 6.2 인형 만들기 화면

인형 만들기는 다음 3단계로 구성한다.

1. **사진 올리기**
   - 사진 선택
   - 사진이 브라우저 안에서만 처리된다는 로컬 처리 안내
2. **얼굴 맞추기**
   - 사진 이동
   - 확대·축소
   - 얼굴 영역을 빈틈없이 채우는 미리보기
   - 사진 다시 선택
3. **이름과 최종 확인**
   - 대상 이름 최대 한글 4글자 입력
   - 흰색 또는 크림색 원피스 위의 붉은 세로 붓글씨 미리보기
   - `인형 완성`

PC에서는 왼쪽에 입력·조절 영역, 오른쪽에 큰 인형 미리보기를 둔다. 모바일에서는 세 단계를 순서대로 보여준다. 인형을 완성하면 자동 저장하고 저주방으로 이동한다.

### 6.3 저주방

- 인형을 화면 중앙에 가장 크게 표시한다.
- 상단 왼쪽에는 나가기 버튼을 둔다.
- 상단 중앙에는 대상 이름을 표시한다.
- 상단 오른쪽에는 저장 상태와 보관함 버튼을 둔다.
- 도구는 화면 아래의 나무 작업함 형태 영역에 배치한다.
- PC에서는 도구 6개를 한 줄로 배치한다.
- 모바일에서는 도구를 3개씩 2줄로 배치한다.
- 선택된 도구는 노란색 테두리로 표시한다.

### 6.4 부적 선택창

- 선택형 저주를 `오컬트 저주`와 `장난 저주`로 구분한다.
- 부적에는 선택한 저주명을 붉은 세로 글씨로 표시한다.
- 부적은 노란색 바탕으로 만들고 인형 얼굴 중앙에 얼굴보다 살짝 넓게 붙인다.
- 부적을 붙이면 해당 저주의 밝고 만화적인 비고어 효과를 실행한다.

### 6.5 내 인형 보관함

- 최대 5개 인형을 카드 형태로 표시한다.
- 카드에는 인형 미리보기, 대상 이름, 마지막 사용 시간, 현재 적용된 부적·바늘·그을림 상태를 표시한다.
- 각 카드에 열기 버튼을 제공한다.
- 추가 메뉴에서 이름 변경과 삭제를 제공한다.
- 삭제 전 확인창을 표시한다.
- PC에서는 카드를 한 줄에 3개씩, 모바일에서는 한 줄에 2개씩 배치한다.
- 저장된 인형이 없으면 얼굴 없는 기본 헝겊인형과 `아직 만든 인형이 없어요` 문구를 표시한다.
- 상단에 `새 인형 만들기` 버튼을 둔다.
- 인형 5개가 모두 저장됐으면 `새 인형 만들기`를 비활성화하고 기존 인형을 삭제해야 한다는 안내를 표시한다.
- 하단에 브라우저 데이터를 삭제하면 인형도 사라진다는 안내를 표시한다.
- 전체 데이터 삭제는 서로 구분되는 확인 절차를 두 번 거친 뒤 실행한다.

## 7. 핵심 사용자 흐름

1. 사용자는 시작 화면에서 서비스명·부제, 로컬 저장 안내, 가상 놀이 안내를 확인한다.
2. `새 인형 만들기`를 선택한다.
3. 지원되는 얼굴 사진을 고르고 로컬 처리 안내를 확인한다.
4. 사진 위치와 확대 비율을 조절해 얼굴 영역을 빈틈없이 채운다.
5. 최대 한글 4글자의 대상 이름을 입력하고 최종 인형을 확인한다.
6. `인형 완성`을 선택하면 인형이 자동 저장되고 저주방으로 이동한다.
7. 저주방에서 6개 도구를 사용하고 상호작용 상태를 로컬에 저장한다.
8. 같은 기기와 같은 브라우저의 보관함에서 인형과 저장 상태를 다시 연다.
9. 필요하면 이름을 변경하거나 확인 절차를 거쳐 인형 또는 전체 데이터를 삭제한다.

## 8. 저주방 도구

저주방은 다음 6개 도구만 제공한다.

### 8.1 바늘

- 도구를 선택한 뒤 인형의 원하는 부위를 클릭하거나 터치해 바늘을 꽂는다.
- 사실적인 상처나 신체 훼손 없이 귀엽고 과장된 비고어 반응을 표시한다.
- 꽂힌 바늘 위치는 현재 상호작용 상태에 포함하여 저장한다.

### 8.2 흔들기

- 도구를 선택한 뒤 인형을 좌우로 드래그한다.
- 손이나 포인터를 놓으면 인형이 통통 튕기며 제자리로 돌아온다.
- PC와 모바일의 포인터·터치 입력 및 키보드 대체 조작을 지원한다.

### 8.3 부적

- 도구를 선택하면 오컬트 저주와 장난 저주 선택창을 연다.
- 선택한 저주명을 표시한 부적을 얼굴에 붙이고 해당 효과를 실행한다.
- 현재 붙어 있는 부적과 선택한 저주는 상호작용 상태에 포함하여 저장한다.

### 8.4 인형 태우기

- 약 1초간 길게 눌러 실행한다.
- 실행 중 인형은 중심축을 기준으로 좌우 약 30도 흔들리고, 밝고 만화적인 불꽃 연출을 표시한다.
- 사실적인 연소, 짙은 연기, 고어 표현은 사용하지 않는다.
- 그을림은 실행 시점부터 1분간 유지한 뒤 자동으로 원래 모습으로 돌아온다.
- 인형 태우기는 저장된 인형 자체를 삭제하지 않는다.
- 그을림 상태와 시작 시각은 현재 상호작용 상태에 포함하여 저장한다.

### 8.5 주문 외우기

- 현재 얼굴에 붙어 있는 부적에 연결된 주문을 2~3초간 길게 눌러 시전한다.
- 별도의 주문 종류를 다시 선택하지 않는다.
- 부적이 없으면 주문 외우기 버튼을 비활성화한다.
- 누르는 동안 주문 문구가 한 글자씩 나타나고 원형 게이지가 채워진다.
- 마이크, 음성 인식, 소리는 사용하지 않는다.
- 주문이 완성되면 현재 부적의 저주 효과를 한 번 더 강하게 실행한다.
- 완료 효과는 작은 별과 천 조각이 터지는 밝고 만화적인 연출로 한다.

### 8.6 정화하기

- 다른 도구와 시각적으로 분리한다.
- 확인창을 거친 뒤 바늘, 부적, 저주 효과, 그을림 등 상호작용 상태를 초기화한다.
- 정화해도 인형의 얼굴 사진, 대상 이름과 인형 자체는 삭제하지 않는다.
- 정화된 상태를 로컬 보관함에 저장한다.

## 9. 부적과 주문

### 9.1 연결 규칙

- 주문 문구는 현재 얼굴에 붙어 있는 부적에 따라 자동으로 결정된다.
- 주문은 현재 부적의 저주 효과를 강화해 한 번 더 실행하며 새로운 저주 종류를 선택하는 기능이 아니다.
- 모든 부적과 주문은 실제 효력이나 정통성을 주장하지 않는 서비스용 창작 표현이다.

### 9.2 오컬트 저주와 주문

1. **만사불통**
   - 주문: `실실 꼬여 길길 막혀, 만사불통 얍!`
   - 효과: 검은 실이나 붉은 실이 인형 주변에서 엉키는 만화적 연출
2. **망신살이**
   - 주문: `감춘 허세 드러나라, 망신살이 얍!`
   - 효과: 인형 주변에 시선 표시가 나타나고 얼굴 또는 입 주변에 창작 봉인 문양이 나타나는 연출
3. **악운강림**
   - 주문: `작은 먹구름 따라붙어, 악운강림 얍!`
   - 효과: 인형 위에 작은 먹구름과 만화적인 번개가 나타나는 연출
4. **앞길봉쇄**
   - 주문: `붉은 실아 길을 막아, 앞길봉쇄 얍!`
   - 효과: 인형 앞에 붉은 실 또는 창작 봉인선이 나타나는 연출
5. **인연단절**
   - 주문: `이어진 실 여기서 끊고, 인연단절 얍!`
   - 효과: 사용자와 대상을 상징적으로 연결하던 붉은 실이 빛과 함께 끊어지는 연출

### 9.3 장난 저주와 주문

1. **양말축축**
   - 주문: `마른 양말 물을 만나, 발끝까지 축축 얍!`
   - 효과: 인형의 양말 색이 젖은 것처럼 변하고 작은 물방울이 떨어지는 연출
2. **겨땀장렬**
   - 주문: `숨은 땀아 솟아나라, 겨땀장렬 얍!`
   - 효과: 겨드랑이 부분에 만화적인 땀방울과 당황 표시가 나타나는 연출
3. **왕여드름**
   - 주문: `작은 점아 크게 솟아, 왕여드름 얍!`
   - 효과: 얼굴에 과장된 스티커 형태의 붉은 여드름 하나가 나타나는 연출
4. **신호연속**
   - 주문: `가는 길마다 빨간불, 신호연속 얍!`
   - 효과: 인형 주변에 빨간 신호등 아이콘이 연속해서 켜지는 연출
5. **엘베놓침**
   - 주문: `한 발 늦게 문 닫혀라, 엘베놓침 얍!`
   - 효과: 인형 앞에서 작은 엘리베이터 문이 닫히는 만화적 연출

장난 저주의 땀, 여드름 등은 사실적인 신체 상태나 질환처럼 묘사하지 않고 스티커·아이콘 중심의 밝고 과장된 표현을 사용한다.

## 10. 사진 처리 정책

- 지원 형식은 JPG, PNG, WebP다.
- 업로드 원본의 최대 크기는 10MB다.
- HEIC는 MVP 지원 대상에 포함하지 않는다.
- 브라우저 안에서 사진을 1024×1024 WebP로 변환·압축해 저장한다.
- 변환 과정에서 EXIF 위치정보 등 원본 메타데이터를 제거한다.
- 업로드 원본과 변환 이미지를 외부 서버, 외부 API 또는 외부 분석 서비스로 전송하지 않는다.
- 사용자가 사진의 위치와 확대 비율을 직접 조절한다.
- 얼굴 자르기나 인식을 위한 외부 API를 사용하지 않는다.

## 11. 저장과 데이터 수명

- 인형 데이터와 변환 이미지는 IndexedDB에 저장하고 IndexedDB 접근에는 경량 `idb` 라이브러리를 사용한다.
- 단순 설정값은 localStorage에 저장한다.
- 저장 가능한 인형은 최대 5개다.
- 인형 생성 완료 후 자동 저장하고, 대상 이름, 변환 이미지, 마지막 사용 시간, 부적·바늘·그을림 상태를 보관한다.
- 그을림 상태를 다시 불러올 때 실행 시점부터 1분이 지났으면 자동으로 정상 모습으로 복구한다.
- 정화 시 모든 상호작용 상태를 초기화하고 정화된 상태를 저장한다.
- 이름 변경을 지원하며 변경 결과는 인형과 카드에 함께 반영한다.
- 인형 삭제 전 확인창을 표시하고, 삭제를 확정하면 해당 인형의 사진·이름·상호작용 상태를 함께 삭제한다.
- 전체 데이터 삭제는 확인 절차를 두 번 거친 뒤 모든 로컬 인형 데이터를 삭제한다.
- 브라우저 데이터 삭제, 시크릿 모드, 기기 변경 또는 브라우저 변경 시 저장 내용이 사라질 수 있음을 안내한다.
- 기기 간 동기화와 클라우드 백업은 제공하지 않는다.

## 12. 기술 스택과 구조

MVP 기술 스택은 다음과 같이 확정한다.

- React
- TypeScript
- Vite
- 별도 UI 프레임워크 없이 CSS 사용
- 얼굴 자르기와 합성은 HTML Canvas 사용
- 흔들림과 일반 UI 동작은 CSS 애니메이션 사용
- 불꽃·재·입자 효과는 필요한 범위에서 Canvas 사용
- 인형 데이터와 이미지는 IndexedDB에 저장
- IndexedDB 접근에는 경량 `idb` 라이브러리 사용
- 단순 설정값은 localStorage에 저장
- 테스트는 Vitest와 React Testing Library 사용
- 별도 화면 라우터 없이 단일 페이지 애플리케이션 상태로 화면 전환
- 백엔드, 외부 API, 사용자 분석 도구는 사용하지 않음

## 13. 개인정보, 안전 및 표현 원칙

- 개인 콘텐츠는 로컬 우선 구조로 처리한다.
- 사진, 대상 이름, 인형과 저주 기록을 서버, 외부 API 또는 외부 분석 서비스로 전송하지 않는다.
- 사용자 사진과 로컬 인형 데이터는 정적 사이트 배포물이나 Git 저장소에 포함하지 않는다.
- 사용자가 저장 위치의 한계와 삭제 방법을 이해할 수 있도록 안내한다.
- 실제 저주 효과나 상대방에게 가해질 현실의 피해를 주장하거나 약속하지 않는다.
- 결과를 다른 사람에게 보내거나 위협하는 용도로 사용하지 말라는 안내를 시작 화면에 표시한다.
- 현실의 위협 메시지 작성·전달을 돕는 기능을 제공하지 않는다.
- 공포·고어·피·사실적인 신체 훼손 및 불쾌감을 유발하는 사실적 묘사를 사용하지 않는다.
- 만 14세 이상 이용을 권장하되 생년월일 입력이나 별도 연령 확인 절차는 만들지 않는다.

## 14. 반응형·접근성·비기능 요구사항

- 최신 주요 브라우저의 PC와 모바일 환경을 지원하는 반응형 웹으로 제작한다.
- 모바일 세로 화면에서 가로 스크롤 없이 핵심 기능을 사용할 수 있어야 한다.
- 모바일 시작 화면의 주요 버튼은 세로로, 저주방 도구는 3개씩 2줄로 배치한다.
- 키보드만으로 핵심 기능에 접근하고 실행할 수 있어야 한다.
- 드래그와 길게 누르기에는 키보드 사용자를 위한 동등한 조작 방법을 제공한다.
- 포커스 상태, 선택된 도구의 노란색 테두리, 저장 상태와 조작 결과를 시각적으로 인지할 수 있어야 한다.
- 모션 감소 환경을 고려한다.
- 개인 콘텐츠를 외부로 보내지 않고 정적 호스팅으로 동작할 수 있어야 한다.

## 15. 저장소와 배포

- GitHub 저장소는 비공개로 유지한다.
- 배포는 Cloudflare Pages를 사용한다.
- Cloudflare Pages가 비공개 GitHub 저장소를 연결해 빌드하는 구조로 계획한다.
- 배포된 웹사이트 자체는 주소로 누구나 접속할 수 있다.
- 소스 저장소와 사용자 콘텐츠는 공개되지 않는다.
- Cloudflare Web Analytics를 포함한 사용자 분석 기능은 활성화하지 않는다.
- 사용자 사진과 로컬 인형 데이터는 정적 사이트 배포물이나 Git 저장소에 포함하지 않는다.
- 실제 배포 연결과 설정은 구현 완료 후 별도 단계로 진행한다.

## 16. MVP 범위

### 16.1 포함

- PC·모바일 반응형 웹과 키보드 접근성
- 로그인과 회원가입 없는 로컬 우선 사용

- JPG·PNG·WebP 사진 업로드와 브라우저 내 1024×1024 WebP 변환·압축 및 메타데이터 제거
- 수동 얼굴 이동 및 확대·축소

- 오컬트 저주 5개와 장난 저주 5개 및 각 부적에 연결된 주문
- 최대 5개의 로컬 인형 보관함과 인형 열기·이름 변경·삭제·전체 데이터 삭제
- 부적·바늘·그을림 상태 저장 및 복원
- 비공개 GitHub 저장소와 Cloudflare Pages 배포 계획

### 16.2 제외

- 남성형 인형
- HEIC 사진
- 회원가입, 로그인, 클라우드 저장, 기기 간 동기화
- 공개 갤러리, 사용자 콘텐츠 검색, SNS 공유, 공개·공유 링크, 사용자 간 소통

- 남성형 인형
- 추가 인형 스킨과 테마
- 사진 없이 사용할 수 있는 얼굴 꾸미기
- 로컬 백업 내보내기·가져오기
- 설치형 웹앱(PWA) 지원

향후 확장 기능도 로컬 우선·비공개·비고어 원칙을 유지해야 한다. 감정 문구 기능은 향후 확장 후보에도 포함하지 않는다. 클라우드 저장이나 계정 기능은 별도의 사용자 결정 없이는 확정하지 않는다.

## 18. 미결정 사항

1. 확정된 공방 방향 안에서 사용할 글꼴, 정확한 간격·크기와 세부 장식 규격
2. 이미 동작이 정해진 길게 누르기·그을림 시간을 제외한 바늘, 흔들기, 각 저주 효과의 세부 강도와 지속 시간
3. 설정 화면에서 제공할 구체적인 설정 항목과 서비스 안내 화면의 상세 구성

## 19. 출시 전 수용 기준

### 19.1 시작과 인형 만들기

- 시작 화면 중앙에 얼굴 없는 기본 헝겊인형, 서비스명, 부제, 두 주요 버튼, 브라우저 저장 안내와 가상 놀이 안내가 표시된다.
- 모바일 시작 화면에서 두 주요 버튼이 세로로 배치된다.
- 사용자는 로그인이나 회원가입 없이 JPG·PNG·WebP 형식의 최대 10MB 사진을 올릴 수 있고 HEIC는 지원되지 않는다.
- 사진은 외부로 전송되지 않고 브라우저 안에서 메타데이터가 제거된 1024×1024 WebP로 변환·압축된다.
- 인형 만들기는 사진 올리기, 얼굴 맞추기, 이름과 최종 확인의 3단계로 진행된다.
- 사진은 얼굴 영역을 빈틈없이 채우며 사용자가 위치와 확대 비율을 조절하고 다시 선택할 수 있다.
- 대상 이름은 최대 한글 4글자이며 원피스 위에 큰 붉은 세로 붓글씨로 미리보기 된다.
- 인형 완성 후 자동 저장되고 저주방으로 이동한다.

### 19.2 저주방과 상호작용

- 저주방의 인형, 상단 정보와 버튼, 하단 나무 작업함이 정의된 위치에 표시된다.
- PC에서는 도구 6개가 한 줄로, 모바일에서는 3개씩 2줄로 표시되고 선택 도구에는 노란색 테두리가 나타난다.
- 바늘은 선택 후 원하는 부위를 클릭하거나 터치해 꽂을 수 있다.
- 흔들기는 선택 후 좌우로 드래그할 수 있고 놓으면 인형이 통통 튕기며 제자리로 돌아온다.
- 부적 도구는 오컬트와 장난 저주 선택창을 열고 선택한 저주명이 부적에 표시된다.
- 인형 태우기는 약 1초간 길게 누르면 좌우 약 30도 흔들림과 만화적 불꽃이 실행되고 그을림이 1분 후 자동 복구된다.
- 주문 외우기는 부적이 없으면 비활성화되고, 현재 부적이 있으면 2~3초간 길게 눌러 실행한다.
- 주문을 누르는 동안 연결된 문구가 한 글자씩 표시되고 원형 게이지가 채워진다.
- 주문이 완성되면 현재 부적의 효과가 한 번 더 강하게 실행되고 작은 별과 천 조각이 터지는 밝은 완료 효과가 나타난다.
- 정화하기는 다른 도구와 시각적으로 분리되며 확인 후 상호작용 상태를 초기화하되 인형 자체는 유지한다.
- 드래그와 길게 누르기를 포함한 핵심 기능은 키보드로도 동등하게 실행할 수 있다.

### 19.3 보관함과 저장

- 최대 5개의 인형을 저장하고 같은 기기와 같은 브라우저에서 복원할 수 있다.
- 카드에 인형 미리보기, 대상 이름, 마지막 사용 시간과 부적·바늘·그을림 상태가 표시된다.
- PC에서는 카드가 한 줄에 3개씩, 모바일에서는 한 줄에 2개씩 표시된다.
- 빈 보관함에는 얼굴 없는 기본 헝겊인형과 `아직 만든 인형이 없어요`가 표시된다.
- 5개가 저장되면 새 인형 만들기가 비활성화되고 기존 인형 삭제 안내가 표시된다.
- 각 인형은 열기·이름 변경·확인 후 삭제를 지원한다.
- 전체 데이터 삭제는 두 번의 확인 절차를 통과해야 실행된다.
- 저장된 그을림은 실행 시점부터 1분이 지났으면 정상 모습으로 복구된다.
- 브라우저 데이터 삭제, 시크릿 모드, 기기 또는 브라우저 변경으로 데이터가 사라질 수 있다는 안내를 확인할 수 있다.

### 19.4 개인정보·표현·배포

- 사진, 대상 이름, 인형과 저주 기록이 네트워크 요청을 통해 서버, 외부 API 또는 외부 분석 서비스로 전송되지 않는다.
- 모든 화면은 따뜻한 한지 인형 공방 방향을 따르며 금지된 공포 소품과 어두운 제단 표현을 사용하지 않는다.
- 모든 연소와 저주 연출은 밝고 만화적인 비고어 표현이며 피·사실적인 상처·신체 훼손을 표현하지 않는다.
- MVP에는 배경음과 효과음을 포함한 소리 기능이 없다.
- 만 14세 이상 권장 안내를 제공하되 생년월일 입력이나 별도 연령 확인을 요구하지 않는다.
- GitHub 저장소는 비공개이며 Cloudflare Pages 배포 시 소스와 사용자 콘텐츠를 공개하지 않는다.
- Cloudflare Web Analytics를 포함한 사용자 분석 기능이 활성화되지 않는다.

- 확정된 서비스명, 주문 문구, 기술 스택, 사진 정책, 연령 기준과 저장소 공개 여부를 미결정 사항에서 제거했다.
